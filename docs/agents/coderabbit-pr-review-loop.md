This repository is governed by the company PR review policy. The policy is not
copied here. It lives in one place, `ospina-company/handbook`, and the review
tools on every workstation carry the current version and keep it current.

Before you prepare, update or merge a pull request:

1. Run `check-review-loop-drift`. It confirms that this file is intact and that
   the policy installed on this machine matches the handbook.
2. Read the policy. `check-review-loop-drift --show-policy` prints the path of
   the installed copy. The same text is at the canonical source named above.
3. Obtain the review of record with `coderabbit-review-of-record <pr-number>`.

If those commands are missing, install them from a handbook checkout:

```bash
bash scripts/agents/install-review-of-record.sh
```

A missing or unverifiable policy is a hard stop. It is never an exemption from
review.

Do not edit this file and do not add repository rules to it. Local rules belong
in `AGENTS.md`. Refresh this file only with the handbook's
`scripts/agents/sync-review-policy.py`.
